- That's fixable in principle — pass a no-op reward function to `gym.make(...)` (so the internal call is inert) and let `StatefulRewardWrapper` own the real DSR computation, same as the anytrading path already does. That's a real, testable pattern, not a structural dead end. But it's new functionality, not a bug fix — it would need its own tests and design sign-off, not something to bundle into an anti-pattern sweep.
